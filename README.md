# Automation Testing Framework

## Tech Stack
- Java
- Selenium WebDriver
- TestNG
- Maven
- Rest Assured

## Project Structure
- src/main/java – framework code
- src/test/java – test cases
- pom.xml – dependencies

## How to Run Tests
1. Clone the repo
2. Import as Maven project
3. Run testng.xml or mvn test
